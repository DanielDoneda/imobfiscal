## Critério de priorização

1. Segurança e isolamento de dados;
2. Jornada mínima demonstrável;
3. Exigências acadêmicas das disciplinas;
4. Redução de erros operacionais;
5. Experiência do usuário;
6. Evoluções comerciais fora do MVP.

## Definition of Ready

Um item está pronto para desenvolvimento quando possui problema, valor esperado, responsável,
dependências e critérios de aceite compreensíveis.

## Definition of Done

Um item é concluído quando o código ou documento está versionado, os critérios de aceite foram
verificados, não há segredo exposto, a evidência foi registrada e a documentação afetada foi
atualizada.
